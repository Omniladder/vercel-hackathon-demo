# 02: Create a short link

> **Status:** Not built yet. The steps describe the planned create page.

A short link is a second address that sends visitors to a long web address. You create one by pasting the long address into the app.

## Steps

1. Log in, then click **Add URL** on the dashboard.
2. Click in the box for the web address and paste or type it. It must start with `http://` or `https://`, for example `https://example.com/a-very-long-page-name`.
3. Click **Create**. The button is greyed out while the app saves.
4. The new short link appears on the screen. Click **Copy** to copy it, or **Back to dashboard** to go back.

## What the short link looks like

The short link has your app's address followed by `/r/` and a short code, for example `https://your-app.vercel.app/r/a7Kq2x`. The code is random, so each link is different even when two people shorten the same address.

## When something goes wrong

- **"Enter a web address that starts with http:// or https://"** The address is missing its start, or it is not a web address. Check the text and try again.
- **"Could not save your link"** The app could not reach the database. Your address is still in the box, so you can click **Create** again.
