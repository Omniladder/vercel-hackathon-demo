# 03: Copy and delete links

> **Status:** Not built yet. The steps describe the planned dashboard.

The dashboard lists every short link you have created, with the newest one at the top. Each row shows the original address, the short link, and the date it was created.

## Copy a short link

1. On the dashboard, find the row for the link.
2. Click **Copy**. The button changes to **Copied** for a moment.
3. Paste the link wherever you need it, such as a chat or a slide.

If your browser blocks copying, the app shows the short link in a box. Click in the box, select the text, and copy it yourself.

## Delete a short link

1. On the dashboard, find the row for the link.
2. Click **Delete**.
3. Click **Confirm** when the app asks you to be sure. Click **Cancel** to keep the link.

After you confirm, the row disappears. The short link stops working, so anyone who opens it will see "This short link doesn't exist."

You can only delete your own links. The app does not show links that belong to other people.

## When the list is empty

If you have no links yet, the dashboard says "You have no short links yet." Click **Add URL** to create your first one. See [02: Create a short link](02-create-a-short-link.md).

## When the list does not load

If the dashboard shows an error, click **Try again**. If the error comes back, see [06: Troubleshooting](06-troubleshooting.md).
