# 04: Visit a short link

> **Status:** Not built yet. The steps describe the planned redirect page.

Anyone can open a short link, whether or not they have an account or are logged in.

## Steps

1. Paste a short link into the address bar of your browser, for example `https://your-app.vercel.app/r/a7Kq2x`.
2. Press Enter. The page shows **Redirecting...** for a moment.
3. The browser opens the original address.

## When the link does not work

- **"This short link doesn't exist"** The code is wrong, or the owner deleted the link. Check the code for typing mistakes. If you copied the link, copy it again.
- **The page stays on "Redirecting..."** Check your internet connection and try again.

## Try it yourself

1. Create a short link for a page you like. See [02: Create a short link](02-create-a-short-link.md).
2. Copy it.
3. Open a private or incognito window and paste the link. The redirect works there too, because you do not need to be logged in to visit a short link.
