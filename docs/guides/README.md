# User guides

These guides show how to use the Short Links app, one task at a time. They are written for workshop attendees, so each one starts from what you see on the screen.

## Guides

| Guide | What you will do |
|-------|------------------|
| [01: Register and log in](01-register-and-log-in.md) | Make an account and sign in |
| [02: Create a short link](02-create-a-short-link.md) | Turn a long web address into a short link |
| [03: Copy and delete links](03-copy-and-delete-links.md) | Share a link and remove one you no longer need |
| [04: Visit a short link](04-visit-a-short-link.md) | Open a short link and see where it goes |
| [05: Log out](05-log-out.md) | End your session |
| [06: Troubleshooting](06-troubleshooting.md) | Fix common problems |

## Before you start

- The app runs in a web browser. Use a recent version of Chrome, Firefox, Safari, or Edge.
- You need an email address and a password of your own. Nothing else is required to try the app.
- To run the app on your own computer, see the setup steps in the [project README](../../README.md).

## Status of these guides

The guides describe the finished app. Some parts are not built yet. Each guide has a status line at the top. If a guide says "Not built yet," the steps are what the app will do, not what it does today.
